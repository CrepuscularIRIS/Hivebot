# T56 回执：暗色 neutral primary 白底白字——换类根治（REA §2.2）

> 施工：main (GLM 5.3) | 2026-11-11 | worktree feat/T56

## 根因（比工单预想深两层）

1. **0.18 的 sentiment 类体系**：`BUTTON_SENTIMENT_CLASSES.neutral.primary` 五类来自 stylex 生成物（computer/shell/view.css）——常态底 `.sand-1wclgxm`=`--sand-fill-primary`（暗≈rgba(250,250,250,.78) 浅底）、字 `.sand-xcaa6e`=`--sand-text-on-primary`（暗 #f5f5f5 白）→ **白底白字**。`sand-xcaa6e` 同时是 accentPrimary 的字色类（REA L6395）——0.18 把 neutral 的字错接到了 accent 的类。
2. **stylex specificity**：这些规则都带 `:not(#\#)` 三连（0,4,0）——普通覆盖规则打不赢（T30d 探针注「原子类赢过规则」即此）。
3. **palette 变量在按钮上下文 UNDEF**（T30d 注释早有记载）——`var(--sand-bg-primary)` 解析空 → 只能亮暗两套直写色值（原版值）。

## 修法

- `sand-kit-primitives.tsx`：`neutral.primary` 五类 → **`sand-t56-neutral-primary sand-1gzh0bn sand-g7klql`**（保留 disabled 底/字两类——原版同语义）。
- `sand-kit-primitives.css` 新类（亮 `#1c1c1c`/`#fcfcfc`、暗 `#f5f5f5`/`#121212`、hover `#363636`/`#dbdbdb`——REA §2.2 原版值），**`:not(#\#)` 四连 (0,5,0)** 压过 stylex 三连；暗色走 **`@media (prefers-color-scheme: dark)`**（与 runtime 主题 installer 同源驱动；`html[data-theme]` 属性选择器实测在按钮上下文不生效，回执记）。
- 删补丁：p5-57.css T30d #1（create-bot 白底黑字）+ T30db #2（transition）+ T30db #3（span 字色）；t7b.css skills-add 暗色字色段。工单验收②的 grep 命中均为 done 工单文档记载（非 css），代码中已无。

## 取舍与坑（记档）

- **onboarding 主钮位砍掉**：onboarding seen 真源在 main 侧 store（bridge.setSeen），localStorage removeItem+reload 复入不了 onboarding；该钮同为 SandButton 同类，色值由前两位实证覆盖。
- **skills-add 位砍掉**：本地 mock 运行时 info pane 无该钮（win 远端才报 Couldn't load skills——queue 已有 T61）；t7b 补丁位由「补丁已删仍过」的 create-bot 位等价证明。
- hover 用 `--sand-bg-primary-hover` 的**值**直写（变量 UNDEF 同因）；原版 hover 语义保留。
- stylex `:not(#\#)` 手法本身照抄用于自护——若日后上游升版改用别的防覆盖手段，此类的四连需同步（注释已记）。
- 深挖路径（三层洋葱：补丁→类映射→specificity→变量作用域→主题时序）每层都有中间红档，LEARNINGS 可引用。
