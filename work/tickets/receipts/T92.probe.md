# T92 探针结论：dsh 会话回滚能力（tray Edit 的前置）

> 探针：main (GLM 5.3) | 2026-11-14 | 纯读（typert.host.js schema + 词汇扫描）

## 结论
1. **`session/fork` 存在**：'Fork one cold-readable exact event prefix into a new Session. An omitted boundary selects the latest completed-turn prefix; an open cut receives synthetic fork closers.'——参数：source session + 可选精确事件边界 + migration preflight。
2. **无同会话回滚**：方法全集 33 个里无 truncate/rollback/rewind/discard（truncat 命中全是只读分页描述）。
3. **tray Edit（0.18 语义：编辑上一条消息重跑）的可行实现=fork**：fork 到「上一条 user 消息前」边界 → 新 session（带合成 closer）→ 改文本发新 prompt。**语义差异（vs 原版同会话 roll-back）**：产生新 session——旧会话保留在 roster（需 UI 决策：归档/隐藏/或 fork 后标记替换）。
4. **T93 开单建议**（交经理）：Edit 按钮（失败卡/消息菜单）→ shim 层 fork+relabel（旧会话自动 rename「 Edited」或隐藏）——**旧会话处置要用户拍板**（Q-062 候选）。
