## 方法（可复核）

1. 分母：`grep -oh '@keyframes ...' | sort -u` = 147（index 145 + desktop-mount-panel 2）。
2. 用途反推：原版是 Panda CSS 原子化——keyframes 定义体（`keyframes.json`：名字+body+偏移）+ 344 条含 animation 规则 + 336 个 `animation-*` 子属性原子 class；组件 JS（样式字典组合串，如 `chunk-widget-DEsXv4qw.js` 的 `elevatedCard:{kKVMdj:\`sand-1ujtcca sand-xnp86f\`}`）拼出 name+duration+easing+fill-mode。配对管线两轮：纯 class-list 字符串正则（44）→ str.find 上下文扫描（99/147 拿到参数；其余 `?` 在报告标明）。
3. transition 侧：327 条含 transition 规则全提取 + 值直方图（高频：.12s/.15s/.2s、cb(.22,1,.36,1)、`linear(33 档)` spring）。
4. 我们现状：源码（overrides/ + frontend/src/recovered/）47 条 animation/transition 声明 + 构建产物 `.build/frontend-shell/assets/index-Bii1kipe.css` 计数（16 keyframes / 9 animation / 16 transition）。
5. JS 行为：scroll-to-bottom 阈值（`distanceFromBottomPx>80`）、jumpToLatestPill、`scrollToEntry(id,'smooth')` 均出自 `index.eager-app-iGTgHP_Q.js` 静态串；声音系统（5 wav + `sand_notification_sounds` gate + 设置键）出自 `index.eager-app` + `chunk-general-pane-YXy_8X5a.js`。

## 核心结论（三行版）

- 量级差：原版 147 keyframes / 344 animation / 327 transition 规则 vs 我们 16 / 9 / 16——0.18 底座同属 sand/ui 原子体系，动画层没跟上。
- P0 缺口：typing 三点动画（我们是静态圆点）、text-shimmer 流式扫光、消息入场 new 双段 + 高亮锚点闪、浮层出入场参数（原版 .18s cb(.22,1,.36,1) vs 我们 200ms ease-sharp）、退场动画整体缺失、wipe 视图切换、发送按压 spring、toast tray。
- 行为流：滚动到底 80px 阈值 + 未读 pill + smooth 跟随是 JS 逻辑，需组件层复刻；声音系统存在但 `isAnysphereUser` gate 默认关（资产版权注意）。
