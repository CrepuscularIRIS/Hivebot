## 1. 根因与修法

**根因**（验证经理线索属实）：hidden-chats 对话框的布局由 0.18 原子类承担（`.sand-1348h9v`/`.sand-z9dl7a`/`.sand-yamay9`/名字 span 的 6 个），这些类的定义在 **0.18 构建产物 CSS**（view.css @evidence 指向 `index-lCyB53CO.css`）——重构树没带原子表源，**本机无 0.18 安装可拆**（0.78.1 已拆 `/opt/Grok Bot/app.asar` → 其类名每版重排、hidden 语义类与 1348h9v 均无），产物 CSS 计数 0 条。逐层实测：dialog 520px → body 容器 28px → list 28 → row 16 → **按钮 8px**（宽度沿内容逐层收缩）。

**修法**：按重构树 `plugins/overlay/browser.css` 先例（作用域限定补原子类布局），在 `hidden-chats/overlay/view.css` 补：
- `.sand-hidden-chats-dialog`：flex column + align-items stretch + padding `var(--cursor-spacing-4, 16px)`；
- `.sand-hidden-chats-dialog > *` 满宽（防 column 子层沿内容收缩——实测修后链 520→488→473→370→名字 327px）；
- header 行排 space-between（× 回到标题行右侧）；
- `.sand-hidden-chats__open` flex + 名字 span `flex:1 1 auto; min-width:0; ellipsis`（与 Unhide 并排不叠）。

数值全部取 `--cursor-*` tokens（回退值 16/12/8/4px 与 tokens 档一致），无自创数值。
