## 施工踩坑（spec 调参，全记）

1. **probe token 求值**：`style.borderTopColor=var(token)` 在 display:none probe 上返回 undefined → 改喂 `color`（色 token 通用）。
2. **两路序列化舍入差**：probe color `rgba(…,0.24)` vs borderTopColor `rgba(…,0.235)`（0x3d/255=0.239 两路舍入不同）→ `sameColor` rgba 元组容差比（分量 ≤2、alpha ≤0.02）。
3. **过渡中途值**：focus 点击后立即读得 0.196（primary 0.24 的中途）；展开立即读 18.30px——态切换后统一 `waitForTimeout(400~500)`（过渡 .15s/.3s）。
4. **合成 drag 事件被忽略**：`new DataTransfer()` 空 transfer 的 types 不含 Files，`hasFileDragData`（composer.tsx:130）直接 return → `dt.items.add(new File([...]))` 带真文件后 overlay 才出现。
5. **暗色轮静息残留**：亮轮结尾 focus 态（primary 0.22）切暗后 rest 未等回落 → rest() 内置 400ms。
6. **静息段 frame 漏取 borderTopColor**：初版色断言 Received undefined——静息 frame 补列。
