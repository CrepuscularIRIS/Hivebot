## Architecture / Tech Stack

- 复用 p6 编排链（app/sdk/src/orchestration/ + start.ts 默认链），不自建。
- UI 壳 app/ui（electron + renderer-grok overrides/shim）；e2e = playwright（`pnpm -C app/ui test:e2e`）。
- 视觉验证新通道：ego browser（computer use）真实窗口截图，对照 deb110 参考图。

## Global Constraints（精确值）

- 合并一律 `git merge --no-ff`，禁整树覆盖；多 worktree 期间禁 `git stash`。
- e2e 必须先 `pnpm -C app/ui build` 再 `pnpm -C app/ui test:e2e <spec>`（run-e2e.sh 新鲜度守卫 exit 78 会拦旧产物；逃生门 PBOTS_E2E_SKIP_STALE_CHECK=1 仅限明确绕行时用）。
- 裸 `sh scripts/run-e2e.sh` 会被 miniconda playwright 截胡（unknown command 'test'）——禁用。
- 隔离 HOME 用 /tmp/bot-<任务>- 前缀；死 DBus；不用 sudo / pkill -f；严禁重启机器。
- 全量回归单线程跑（H3 长链并行互踩曾致 create-live 假红）；GPU load>40 停全量。
- 每个任务合并后立即定向回测，结果记 work/LOG.md。

5. 开闸一行改动引发默认链回归 → 任务 1.6 开闸后跑全量 sdk 单测 + orchestration e2e，不只跑新用例。

## 测试分工协议（用户规则 2026-11-17）

- **主 agent（本会话）**：开发、写测试代码、commit、合并、验收判断。

- **回报契约**（flash 每次必须带回，缺一即打回）：
  1. 命令原文 + 退出码（不裸贴长日志，只贴失败尾部）
  2. 截图绝对路径（ego browser 走查每次关键状态一张）
  3. 清单逐条 ✅/❌ + ❌ 的现象描述
- **证据红线**：主 agent `read_image` 亲验截图后才可写进回执/宣布通过；flash 不得修代码、不得 commit、不得合并；失败只报现象与日志定位，修复回到主 agent。
- 安全单验收（T73d/T93 链）仍走经理流程，不因本协议绕过。
