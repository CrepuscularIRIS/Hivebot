## 1. 第 0 步探针（先于实现，通过）

临时 patch 挂 `p2sdk-workspace`（remoteRoot=$PBOTS_DATA_DIR）起 serve → fetch 换 cookie 调 `p2sdk/workspace_ensure`（botId t46d-probe）：
```text
result: {"ok":true,"value":{"path":"/tmp/t46d-probe/data/workspaces/t46d-probe","canonical":"…/workspaces/t46d-probe"}}
ls /tmp/t46d-probe/data/workspaces/ → t46d-probe     ← 目录真落宿主盘（掩蔽 CONFIG_DIR 下 ctx.subprocess mkdir 可行）
```

## 2. 实现（三条定案全落）

1. **`serve --connect`**（锁前只读）：读 serve.json→pid 活→从 handoff 读 launch-token+remote-root → stdout `HIVEBOT-CONNECT {"base_url","token","remote_root","version"}`。失败路径全走 stderr 且**只打完整小 JSON**：不在跑 `{"running":false}`、pid 死 `{"stale":true}`、handoff 异常（路径形状/文件缺/空/token 字符集/remote_root 含引号反斜杠空白）`{"error":"handoff-incomplete"}`——token 唯一出 stdout 的地方且只在显式调用时。
2. **workspace 挂载**：launcher 在**锁段后、SDK 起前**（第一版放 serve 分支内太晚——SDK 第 3 段已起 patch 已写，实测定位后提前）`export P2SDK_WORKSPACE_ROOT="$PBOTS_DATA_DIR"`；start.ts：cfg.workspaceRoot（resolveConfig 读 env）→ 本机模式（`cfg.ssh === undefined`）时 runtime-patch 插 `p2sdk-workspace` 行（remoteRoot=值）+ handoff 行带 `remoteRoot`（**无 sshMode**——Ubuntu 本机桌面 main 仍走本机分支）；ssh 同时设时 env 忽略（ssh.remoteRoot 优先）；childEnv 删该键（launcher-only，照 PBOTS_DATA_DIR 做法）；env 未设逐字不变（ⓑ+T9a 既有格钉）。
3. **符号链接**：`REPO_ROOT` 改 `readlink -f "${BASH_SOURCE[0]}"` 求真路径——`ln -s <repo>/app/launcher/hivebot ~/.local/bin/hivebot` 后经链接可调（⑨）。
