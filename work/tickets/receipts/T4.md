## 4. 施工事故（如实）

1. **未跟踪文件上的变异污染**：变异还原误用 `git checkout --`（对未跟踪文件无效），M1–M3 改动累积污染测试文件，且备份时机错误存了坏版。恢复：按编辑历史逆向重建（漏了 disable 行与 M3 env 行各一轮，靠 4/4 复验+grep 计数定位）。教训：变异测试的绿版备份必须在变异前落盘，还原必须 `cp` 备份。
2. **合并跑 50% 闪红（⑥）**：dispose 的 `-O cancel` 控制连接是 fire-and-forget，扫描抢在自然退出前——取证显示残留 PID 在读取 /proc 时已 ENOENT。修复在夹具 stop()（两段限界宽限），`ssh-host.test.ts` 保持零改动（工单边界）。
3. 一次 `git checkout -- tests/support/ssh-host.ts`（M2 取证锚未中后的还原动作）抹掉全部未提交夹具改动——整文件重写恢复，三轮 14/14 验证。同 1 的教训：worktree 内未提交的大改 + git checkout 组合危险。
