探针原样：
```text
bslash         rc=1 stdout_nl=0 empty err=HIVEBOT-CONNECT {"error":"handoff-incomplete"}
CR             rc=1 stdout_nl=0 empty err=HIVEBOT-CONNECT {"error":"handoff-incomplete"}
U0001          rc=1 stdout_nl=0 empty err=HIVEBOT-CONNECT {"error":"handoff-incomplete"}
LF-mid         rc=0 stdout_nl=1 BAD-JSON err=
TAB            rc=1 stdout_nl=0 empty err=HIVEBOT-CONNECT {"error":"handoff-incomplete"}
space          rc=0 stdout_nl=0 json-ok err=
dquote         rc=1 stdout_nl=0 empty err=HIVEBOT-CONNECT {"error":"handoff-incomplete"}
trailingLF     rc=0 stdout_nl=0 json-ok err=
cjk-utf8       rc=0 stdout_nl=0 json-ok err=
cjk-Clocale    rc=1 stdout_nl=0 empty err=HIVEBOT-CONNECT {"error":"handoff-incomplete"}
DEL            rc=1 stdout_nl=0 empty err=HIVEBOT-CONNECT {"error":"handoff-incomplete"}
```
（`stdout_nl` = 去掉末尾换行后的换行数；1 = 两行。trailingLF 被 `$(cat)` 剥掉，合法。）

严重度：token 本就只经 `--connect` stdout 给 ssh 调用方，不是新泄漏面；问题是输出协议被打破（半截 JSON + exit 0），T46b 按一行解析会拿到残缺记录。实际 remote-root 来自 `$PBOTS_DATA_DIR`，带换行要靠病态的 `XDG_CONFIG_HOME`，概率低。但这是本单定案逐字写明要拒的「控制字符」，且是安全面单，修法一行，不放行。
