## 设计取舍（记档）

- **种子时机在 handoff ready 行之后**（ready 行是 handoff 插件打的、launcher 无法回溯拦住它再打）——UI 可能在种子落地前连入，容忍：种子毫秒级，e2e ①用轮询 20s 兜（实测秒内到）。launcher stderr 落 `p2sdk: default llm route seeded (user-level settings)` 一行可观测。
- 「用户删掉路由重启是否再种」：**再种**（工单默认口径——无路由=无模型可用；describe 无 litellm 即种，与首启同一条路）。e2e ③间接覆盖反面（改过不覆盖）。
- `writeRuntimePatch` 里加的是 **config patch 行**（`- id: agent-default-model config:…`，非 insert）——同文件既有行都是 insert（要绝对插件名），config patch 行是 p2sdk.yml 语义（整行替换 config），两者在 runtime overlay 里都合法。
- mock 模式**不种**（不 describe 不 mutate，③断言零调用）——mock 无需路由，llm-replay 自带。
