# B12 · composer 听写（dictation，输入面余量）

## Goal
输入面补听写：composer 麦克风钮 → Web Speech（webkitSpeechRecognition，Chromium 内建零后端）→ 临时文本流式进编辑器 → 定稿入正文。1.1.0 原版走 xAI 云语音流（pushAudio/dictation-text RPC），HiveBot 无该后端——UI 语义对齐（provisional/定稿两态），通道换本地 Web Speech。

## Architecture
- overrides/modules/composer.tsx：工具行加 MicButton（SandIconButton aria-label="Dictate"）。
  - 态：idle→recording（aria-pressed=true+红点样式 data-dictating）。
  - 事件：click 开 recognition（lang=navigator.language）；onresult 累积 transcript；interim 段渲染为编辑器尾部灰色临时文本（1.1.0 dictationProvisional 同位）；final 段 append 正文。
  - 再点/blur/onend 停止（recognition.stop()）。
- 不动 shim/数据层（纯 renderer 本地能力，无持久化）。
