## 故障恢复链（为什么前两轮全黑）

1. 四帧纯黑同 md5 的根因不是屏幕内容——是 **Windows 会话注销**（console 非 Active），任何截图手段都拍不到 Session 1 的屏幕（ssh 是 Session 0，CopyFromScreen 直接 Win32Exception——跨会话 GDI 不可访问，实测）。
2. 恢复：注册表 AutoLogon（hivebot / 明文密码）+ `powercfg` 关显示超时 → 重启 → AutoLogon 未自动生效但显示复活 → vncdo 键盘输入密码登录成功 → console Active。
3. **唤醒改鼠标移动**（`vncdo move`）：第一轮用 key shift 唤醒触发 **Sticky Keys 弹窗污染画面**，Enter 关闭后重拍。
