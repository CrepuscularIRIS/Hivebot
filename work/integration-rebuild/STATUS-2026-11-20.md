## 3. 测试方法（分层 + 盲区）

| 层 | 工具 | 覆盖 | 盲区 |

| 单元 | vitest（superagent 20/20 [实跑：本轮]） | 纯函数（master-id/lock-recovery 等） | 不碰引擎 |

| UI 走查 | ego browser 开引擎 URL + CDP dump | composer/侧栏/群聊面板 | **无测量断言，肉眼+DOM dump**；未固化为可重放轨迹 |
| 崩溃注入 | kill -9 + 重启 | stale 锁自愈 | 只测过一种 kill 形态 |
| 长任务 | R16 competitive analysis 剧本 | 多 bot 真任务全链 | 单次执行非回归 |

**环境地雷**（Codex 必读）：`ELECTRON_RUN_AS_NODE=1` 必剥；npm 走 npmmirror；
引擎 kill 用 `ps aux | grep 'resources/app/src/host.mjs'`（pgrep -x node 不中）；
多引擎互抢锁；`/tmp` 会被 sweep；DISPLAY=:0 是用户真桌面禁 GUI 注入。
