1. **名册口**：`ctx.sessionController.list()` → `{items:[{sessionId, updatedAt, running, blank, cwd, projections}]}`——**title 在 `items[].projections.values.title`**（顶层无 title 字段；agent 对象 title=undefined 不可用）
2. **inject**：`['agents','sessionController']`（sessionController 是 gateway session/list 同源控制器；proto 面含 list/search/rename/state）
3. **rename 广播** `session/event` type=`session/title`（data.title 即新名）——缓存刷新时机之一
4. **text() 契约同步**（routing-prompt 同款）→ 名册走缓存：构造时刷 + agent/created/disposed + session/title 三事件驱动 + text() 每次组装 kick 异步兜底（下一次组装即新鲜）
