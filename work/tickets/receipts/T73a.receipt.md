## 施工方倾向（工单验收 3，经理复核）

**P1 路**。理由：
1. **目标语义零改造直达**：「装上后所有 bot 直接可用」= `enabled:true`；热生效（已有 bot 下一轮）、重启持久、新 bot 全拿到——四格全绿，无一处需要 p2temp 或 preset 重注册。
2. **坏包安全**：激活失败被 dsh 结构化拒（failed+诊断），不拖垮任何 bot/连接器——「连接器坏了 bot 还能用」免做。
3. **关闭/卸载语义同样干净**：`setBundleEnabled(false)` 热撤工具——T73c 的 Clear、未来的账号级开关（原版 `setGrokConnectorEnabled` 对应物）都有现成底座。
4. p2temp 勾选链与 profile 级并存无重复——**现行建 bot 勾选 UI 可以保留**（等价超集），T73d 的改动面收缩为：M1 `enabled===false` 守卫放开 + renderer `market-store.install` 发 `enabled:true` + 相关文案（「pick it」句删除）。

## 与 REA 报告的对齐

RE-CONNECTOR-GRANT-0.78.1.md：原版=账号作用域一次 Connect 全局生效、准入在用时审批卡。P1 路的 `enabled:true` 正是「账号作用域全局生效」的 dsh 等价物；「用时准入」由 T73b（standing-grants 门）/T73c（审批卡）补——三张单合起来即原版行为。

## 踩坑

1. `p2temp/session.createWithConnectors` 拒绝空 connectors 数组（`must be a non-empty array`）——「无连接器 bot」用 `session/create`。
2. 探针跑法：node 22.23 `--experimental-strip-types` 直 import `tests/support/runtime.ts`（纯类型剥离可行，无 enum/namespace）；`launchRuntime({env:{P2SDK_HOME}})` 复用同 HOME 重启。
