> 席 C 回报代录，未经改写（2026-11-03）

1. **核心旅程 / 信息层级**：打开会话看正文 → 有 reasoning 时看到独立「思考」行 → 点击查看、再次点击收起 → 切走 bot → 对方产生消息 → 返回后从唯一未读线定位新增内容。最容易卡在"切回即清未读，分隔线同时消失"；解法是进入时先捕获未读边界，再清侧栏角标，本次浏览保留该线。正文第一层，thinking 第二层，时间仅作弱导航；不自动展开 reasoning、不抢焦点、不强制跳到底。
2. **Thinking 交互**：真实 reasoning 非空才生成行，不能把现有三点等待气泡伪装成 reasoning；默认收起，整行原生 button，Enter/Space 切换，提供 `aria-expanded` 与 `aria-controls`。行内顺序为 accent thinking 图标 /「思考」/ 单行省略预览 / chevron；展开在原位显示完整文本，保留换行并可选择复制，不再包 assistant 气泡。按稳定条目 id 保存本次挂载期间的展开状态，后续 chunk 不重置；展开不触发现有"新消息"胶囊。
3. **时间阈值与证据缺口**：已查原版 `transcript.tsx:701`，这里只消费 `time-separator`，`model.ts` 只有类型；对重构前端源码检索未找到生成器或阈值，**不能声称阈值是 5/15/30 分钟**。实现前须由派发者补查原版生成逻辑，测试注释引用确切路径与值；未确认前不把任意阈值当验收基准。拟定规则为相邻有效消息时间差严格 `> T` 插一条，同阈值内及恰等于 T 不插；thinking/tool 子行不制造重复分隔，缺失时间不以接收时钟补造。时间显示本地化、跨日带日期；与未读同位置时顺序为时间 → 未读 → 首条未读消息。
4. **未读规则及现有接缝**：按 bot 隔离，以离开时最后已见消息的稳定身份确定首次新增消息；重回后恰一条线，后续到达消息不移动起点；加载旧历史、重连快照不能凭空制造未读，自发消息、thinking chunk、工具状态更新不计新增消息。无未读不显示；首次加载且没有已见基线不标整段历史为未读；本次线保留至离开，下一次进入重新判定。当前 `/home/lingxufeng/bot/app/ui/renderer/shell/store.ts:273-274` 选择 bot 即清布尔角标，且只读布尔值无法恢复边界；该文件不在任务区域，frontend-dev 应向派发者报告最小区域扩展需求，不能暗加后端字段或伪造边界。
5. **样式数值表（原版确认值 / 提议分开）**：确认：thinking label `11px/600`，图标盒 `16×16px`、字形 `14px`、色取现有 accent token；0.18 行 `min-height:34px;padding:7px 9px;gap:8px`，preview `10px`，detail `10px;padding:0 10px 10px 25px;max-height:220px`。时间 `11px;text-align:center;margin:0 0 22px`，不是四边 22px；未读 `11px;gap:10px;margin:22px 0`，两翼 `1px` 线。提议：弱文字映射现有 tertiary token，未读字映射 accent、线用现有弱强调 token，亮暗不硬编码原版绿；thinking 用透明裸行，不复制旧 tool 描边卡，chevron 采用 right/down 以衔接 R2 B6；新增框/箭头几何如需偏离交 GU。容器现有 `gap:22px` 与上述 margin 必须核算实际间距，避免额外包装再叠一层 gap。
6. **状态全集**：加载沿用会话 skeleton，不画假时间/未读线；空会话沿用现有引导；未收到 reasoning 时沿用三点等待，不展示空 disclosure；长任务有真实 reasoning 才持续更新其内容；失败/停止保留已收到 reasoning，由现有失败/停止 notice 表达结果；离线保留已加载内容且 disclosure 仍可用，沿用离线横幅；需要审批仍由现有 inline 审批卡和提示条承接，不让 thinking 冒充"等待用户"；reduced-motion 下无新增旋转/高度动画。
7. **布局草图（同一会话屏三态）**：收起 `正文 / [thinking-icon 思考 预览… >] / 最终回复`；展开 `正文 / [thinking-icon 思考 预览… v] / [换行文本，最多220px内部滚动] / 最终回复`；返回未读 `旧消息 / [居中时间] / ── 新消息 ── / 首条未读消息 / 后续消息`。全文不 live announce；只保留既有任务状态播报，避免 reasoning chunk 被逐字朗读。
8. **测试 / 反提案 / 复用**：`visual-session.spec.ts` 建议锚点 `data-thinking-row`、`data-thinking-detail`、`data-time-separator`、`data-unread-divider`、稳定消息 id；覆盖 fake reasoning 的鼠标及键盘开合、定稿不重复、无 reasoning 无行，T−1/T/T+1 与跨日/缺时，切走→多条新增→切回唯一线且位于首条之前、持续新增不移位、分页/重连不重复、bot 隔离、亮暗 computed 值及原有80px跟随/分页锚点不回归；①—⑤由测试取证，⑥交 GU，不自称通过。反对"每条消息都打时间 + 返回立即清线 + reasoning 默认展开"，这会把辅助信息变成主内容并丢失阅读边界。复用本地 `Conversation.tsx` / `Markdown.tsx` / Icon，不引依赖；参考 `b-nnett/grok-bot-0.18-reconstructed@a9f633e:frontend/src/recovered/features/conversation/workspace/{transcript.tsx,view.css}`（无 LICENSE，闭源重构，仅依项目私用约束参照）；`01-boot.png` 是登录封面，只能参考全局克制风格，不能作为 B7/B14 几何证据。
