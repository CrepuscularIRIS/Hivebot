## 1. 做了什么

`app/launcher/hivebot` 加 `serve` 子命令：复用锁/密钥/env 文件逻辑，**只起 SDK 不起 Electron**，常驻到 TERM/INT（走既有 cleanup：SDK TERM→KILL、handoff 清理）。ready 后 stdout 打一行机器可读状态 `HIVEBOT-SERVE {"base_url":…,"handoff":…,"pid":…,"version":1}`（token 不出 stdout，留在 handoff 文件——Windows 侧取 token 走 `ssh host cat <handoff>/launch-token`，T46b 对接）；写 `serve.json`（cleanup 兜底删）。`serve --status` 只读查询（锁前、不持锁）打同一格式行；不在跑 exit 1。UI 产物前置检查按模式跳过（serve 不需要 Electron/渲染产物）。
