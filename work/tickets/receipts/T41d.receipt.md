## 1. 根因（e2e 实测定案，非猜测）

**现象 2（按钮被压）**：布局 dump 实测——底栏两元素（account `left:16/bottom:16`、plugins-entry `left:60/right:17/bottom:16`）是 **absolute z:3**，来源是**我们自己的 P5-55 布局覆盖**（`overrides/p5-55-layout.css:74/:90`，上游 css 与 style 标签均无 absolute——matched-rule 遍历实证）；而 Hidden Bots 按钮挂在 Renderer grid 第 2 行**正常流**（sidebar b=776 之后、视口底 820），与底栏（t=768-804）交叠 28px 被盖。

**顺带项（一条滚动）**：list 被压 28px（row 46 装不下）——产物 CSS 实测 `.sand-exx8yu { height: var(--cursor-height-lg) }`（=28px，图标尺寸类）命中对话框 body 容器，把它钉死。

## 2. 修法（按根因，不堆压）

1. `overrides/p5-55-layout.css` 追加一段：按钮（`button:has([aria-label$=" hidden bots"])`，页面唯一）入**同一 absolute 布局层**——`left:16/right:17/bottom:56/z:3`（bottom 56 = 底栏高 36 + 底距 16 + 间隙 4；左右与 plugins-entry 同参）。挂载处未动（ProductionRenderer 不改）。
2. `hidden-chats/overlay/view.css`：`.sand-hidden-chats-dialog > div:not(header) { height: auto !important }` 解 28px 钉死（修后 dialog 158px、body/list 46px 恰装一条，`height:fit-content` 试验无效已撤——28 钉死才是根因）。
