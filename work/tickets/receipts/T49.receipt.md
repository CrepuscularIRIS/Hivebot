## 实现要点（工单边界逐条）

- **D9 放宽**：`^credentials` 整拒 → `^credentials/(describe|set|unset)$` 之外仍拒（文件注释写 Q-047 原话+日期）；`^account`、`/permission`、configForms 不动（⑦）。
- **放行 5 法**：credentials/describe|set|unset、settings/describe、settings/mutate（探针定论：update 在 llm-pi-ai 因 patch !!js 恒炸，DSH Models 页官方写法即 mutate）。
- **set/unset 引用名**（工单改单版「user 层 settings/describe 里出现过的 apiKeyEnv 或 `<ROUTE>_API_KEY`」的实现口径）：静态守卫 `P2SDK_LLM_API_KEY | ^[A-Z][A-Z0-9]*_API_KEY$`，排除 `DSH_` 前缀。**等价论证**：user 层的 apiKeyEnv 只能经 settings/mutate 写入，而 mutate 守卫已把它锁死为「本 route 的 deriveKeyRef 派生名（litellm 额外 P2SDK_LLM_API_KEY）」——所以「user 层出现过的 apiKeyEnv」恒 ⊆ 本守卫集合，且不依赖一次 describe 的时效。若经理验收要求真读 user 层，返修点在 `SETTABLE_REF_RE` 处换数据源。
- **mutate 守卫（经理加的重点）**：ns 锁 llm-pi-ai；op 只许 set/unset（DSH Models 页实际用法——`client.js:1736/1956` set、`1962/2394` unset，path 都是 `[...base,key]`=`['providers',route]`）；route `^[a-z0-9][a-z0-9_-]{0,63}$`；value 纯 JSON（JSON.stringify 兜底，IPC 结构化值天然无函数/无 !!js）；**apiKeyEnv 必须 === `<ROUTE 大写,- 换 _>_API_KEY`（litellm 额外放行 P2SDK_LLM_API_KEY），违规 forbidden + dsh 0**——防「写 baseURL+宿主任意 env 名」外泄凭证。
- **回包**：describe 逐条目只保 configured/source/writable（④，防上游加宽）；set/unset ok 回值一律置 undefined（只写不读）；错误照透传（⑧断言错误消息与 main 日志都不含 value 原文）。
- wire 形态：credentials/settings 都是顶层参数无 `{request:…}` 壳（探针 gateway 报错原文为证）。
