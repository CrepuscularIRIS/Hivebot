## 取证

四问逐条（详细锚点见 RE 文档对应节）：

1. **原版 UI「停止」入口**（RE §1）：文字聊天**没有任何停止入口**。"Stop generating/response/replying/streaming" 全 0（`grep -rl 'Stop generating' /tmp/t78-asar/dist/renderer/assets/` → 无）。仅有的 "Stop" UI 三处且都不是聊天停止：`Stop`（i18n `ygCKqB`，唯一消费在 `chunk-box-desktop-modal-CN4iwwJC.js` 的 `onStopControl`＝box 远程接管弹窗）、`Stop dictation`（`9QwrMz`，听写）、`Reply STOP to stop texts`（`Xk2FSz`，短信退订）。消息菜单只有 Copy/Edit/Delete/Pin/Retry。
2. **点击后行为链**（RE §2）：桌面 renderer 唯一停止 RPC 是 `interruptAgentRun`（客户端表 `grep -o 'interruptAgentRun:{args' index.eager-app-iGTgHP_Q.js`；服务端 proto `InterruptGrokBotAgentRun` 请求 `{agent_id, reason, session_id?}` 响应 `{hadActiveRun}`，**本地无实现＝云端**），但聊天 UI 从不调用；唯一调用点 `DJt` 被 `chunk-view-ODc_03uE.js` 用于「更新/重置电脑」前停所有 agent。真正的叫停 = **发新消息**：turn 运行中消息不排队直发（`isAgentRunningAtSendStart` 仅打标记；仅离线才 `queued` 且可 `cancelQueued` 撤回，失败文案 i18n `8gi/JY`）；0.18 host 侧 `send-turn-dispatch.ts:132` `runner.interrupt("superseded by a new user message", {carriesRecovery})` → 旧 turn abort、新 turn `enqueueExclusiveRun` 排队。
3. **停后呈现与下一轮恢复**（RE §3）：桌面无「已停止」系统行；turn 徽章 `stopped`("Stopped")/`interrupted`("Interrupted")，其中 interrupted 是陈旧推断（running 超 1h 或 agent 停超 60s，函数 `u0t`）；后台任务卡 `endedBy:"cancelled"` → "Cancelled"。**外部渠道**有回执行行：`messaging.turnStopped` = "Your Bot stopped what it was doing."。半截流文本保留不 settle（0.18 `turn-runtime.ts:390-404` finalize "cancelled" 后直接 return）；下一轮靠新 turn 看到完整 transcript + recovery prepend（`wouldRecoverViaPrepend`），系统提示要求先 ack 再继续（`system-prompt.ts:84,105`）；无「上回被打断」专门提示词。
4. **语音 talk-over-you 是否进文字聊天**（RE §4）：**否**。该段 prompt 开头即 "on a live phone call"（`main-app.cjs` 搜 `"## Role & Persona"`），配套 `caller-interrupted` 事件与 `dropped_caller_barged_in` 结局全在语音循环；`[Interrupted mid-reply after: …]` 在产物内只有 2 处且均为提示词文本，运行时注入在服务端语音栈。
5. **StopButton 对照差距**（RE 差距清单表，5 条）：① 原版无聊天停止钮，我们多一个（chat-header.tsx:13）；② 原版叫停＝发新消息 supersede 旧 turn（对话连续），我们＝session/cancel 杀进程树（interrupt.test.ts ≤5s 全退）后无后续 turn；③ 原版停后有可见回执（渠道行/徽章），我们无 transcript 标记；④ 半截消息处置原版明确保留，我们未验证；⑤ 原版新 turn 有「先 ack 再继续」约束 + recovery 上下文，我们续发可回复但无此约束（与 T80 persona 重叠）。
